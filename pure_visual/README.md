# pure_visual 目录说明

这个目录存放的是项目里的纯视觉分割部分，也就是不依赖文字提示词、只看超声图像本身的分割模块。

它的作用主要有两个：

1. 作为项目的纯视觉基线
2. 作为后续视觉语言模型的视觉分支初始化来源

## 当前目录里的文件

### `class_maps.py`

这个文件定义了当前项目使用的类别信息，最重要的是 A4C `13` 类结构名称。

它的主要作用是：

- 统一训练、评估、推理时的类别顺序
- 保证前后端和评估脚本用的是同一套标签口径

### `mobileunet_fpn.py`

这个文件实现了纯视觉基线模型 `MobileUNet-FPN`。

它的主要作用是：

- 接收超声图像
- 输出 `13` 类语义分割结果
- 为 `train.py` 提供模型定义
- 为视觉语言模型提供可继承的视觉结构参考

## 这个目录在整个项目中的位置

从项目流程看，`pure_visual` 负责的是第一阶段：

1. 先用 `train.py` 在 `prepared/a4c13` 上训练纯视觉模型
2. 得到纯视觉最佳权重
3. 后续 `train_vlm.py` 可以把这份纯视觉权重加载进提示式模型

也就是说：

- 如果只想做传统语义分割，主要看这个目录
- 如果想理解申报书里的“大模型 + 纯视觉融合”，这个目录也是必须保留的

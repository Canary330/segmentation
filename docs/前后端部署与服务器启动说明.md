# 前后端部署与服务器启动说明

这份文档只做一件事：把当前仓库重构后的启动方式讲清楚。

现在仓库已经前后端分离：

- `backend/`：服务器端
- `frontend/`：本地前端

## 1. 哪些内容放到服务器

如果你只是想把当前最优结果直接跑起来，服务器端至少需要这些内容：

- `backend/`
- `server_artifacts/20260321_proposal_best/files/best.pt`

建议的服务器目录结构：

```text
/root/autodl-tmp/project/segmentation/
├── backend/
├── server_artifacts/
│   └── 20260321_proposal_best/
│       └── files/
│           └── best.pt
└── ...
```

如果你后续还要继续训练，也建议把这些一起放到服务器：

- `prepared/`
- `FOCUS-dataset/`
- 公开数据目录

## 2. 哪些内容留在本地

本地主要保留：

- `frontend/`

最重要的是：

- `frontend/flutter_frontend/`

本地不需要加载模型权重，也不需要文本编码器。

## 3. 服务器上必须额外准备什么

除了仓库代码和 `best.pt`，服务器还必须准备：

- Python 环境
- `backend/requirements.txt` 里的依赖
- 文本编码器 `clip-vit-large-patch14`

当前推荐用 `ModelScope` 下载文本编码器到本地目录：

```text
/root/autodl-tmp/modelscope_cache/AI-ModelScope/clip-vit-large-patch14
```

## 4. 服务器最短启动命令

下面这组命令的目标是：

- 不重新训练
- 直接跑当前最优结果

### 4.1 安装环境

```bash
cd /root/autodl-tmp/project/segmentation
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r backend/requirements.txt
pip install modelscope
```

### 4.2 下载文本编码器

```bash
python3 - <<'PY'
from modelscope import snapshot_download
snapshot_download(
    'AI-ModelScope/clip-vit-large-patch14',
    cache_dir='/root/autodl-tmp/modelscope_cache'
)
PY
```

### 4.3 设置环境变量

```bash
export SEGMENTATION_MODEL_PATH=/root/autodl-tmp/project/segmentation/server_artifacts/20260321_proposal_best/files/best.pt
export SEGMENTATION_TEXT_ENCODER=/root/autodl-tmp/modelscope_cache/AI-ModelScope/clip-vit-large-patch14
export SEGMENTATION_IMAGE_SIZE=384
export SEGMENTATION_BINARY_THRESHOLD=0.5
export SEGMENTATION_MULTICLASS_THRESHOLD=0.15
```

### 4.4 启动后端

```bash
uvicorn backend.api.main:app --host 0.0.0.0 --port 8000
```

### 4.5 检查后端是否起来

```bash
curl http://127.0.0.1:8000/health
```

正常会返回类似：

```json
{"status":"ok","model_loaded":false,"checkpoint_configured":true}
```

## 6. 本地必须开的端口

这一点要记住：

前端不是直接访问服务器 `8000`，而是通过本地 SSH 隧道访问。

你本地必须开这个端口转发：

```bash
ssh -p <服务器端口> -L 18000:127.0.0.1:8000 root@<服务器地址>
```

这条命令的含义是：

- 本地打开 `18000`
- 转发到服务器的 `127.0.0.1:8000`

所以前端里应该填的地址固定是：

```text
http://127.0.0.1:18000
```

## 7. 本地前端启动命令

```bash
cd frontend/flutter_frontend
flutter pub get
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:18000
```

## 8. 现在真正的最短使用路径

如果你想最快把现在的结果跑起来，按这个顺序做：

1. 把仓库传到服务器
2. 确保服务器上有 `backend/` 和 `best.pt`
3. 在服务器安装 `backend/requirements.txt`
4. 在服务器下载 `clip-vit-large-patch14`
5. 在服务器运行 `uvicorn backend.api.main:app --host 0.0.0.0 --port 8000`
6. 在本地执行 `ssh -L 18000:127.0.0.1:8000 ...`
7. 在本地启动 `frontend/flutter_frontend`

做到这里，前端就能直接调用当前最佳模型。

## 9. 如果以后要重新训练

除了上面的部署内容，服务器上还需要：

- `prepared/`
- `FOCUS-dataset/`

训练主入口分别是：

```bash

python3 backend/train_vlm.py
```

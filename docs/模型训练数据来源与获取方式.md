# 模型训练数据来源与获取方式

这份文档专门说明三件事：

1. 当前模型到底用了哪些数据训练
2. 这些数据分别起什么作用
3. 这些数据在本地和云端应该怎么获取、怎么摆放

## 1. 当前项目实际用到的数据

当前主线模型训练一共涉及两类数据：

### 1.1 目标域数据

这是你自己的 `13` 类 A4C 标注数据，也是整个项目最终任务的数据基础。

当前来源：

- 原始 XML：
  [training2.xml](/Users/mico/Documents/za/git/segmentation/标注/training2.xml)
  [validation2.xml](/Users/mico/Documents/za/git/segmentation/标注/validation2.xml)
  [testing2.xml](/Users/mico/Documents/za/git/segmentation/标注/testing2.xml)
- 原始图像目录：
  [FOCUS-dataset](/Users/mico/Documents/za/git/segmentation/FOCUS-dataset)

它的作用是：

- 定义项目最终的 `13` 类标签体系
- 用于纯视觉基线训练
- 用于提示式视觉语言模型的目标域精调
- 用于最终 `13` 类测试评估

当前固定标签为：

- `DAO`
- `LA`
- `RA`
- `LV`
- `RV`
- `VS`
- `IS`
- `SP`
- `RB`
- `LVW`
- `RVW`
- `LL`
- `RL`

### 1.2 公开辅助数据

这是公开的 `Fetal Echocardiography Second Trimester` 数据集。

当前作用不是替代你的 `13` 类任务，而是作为辅助预训练信号。

它的作用是：

- 帮助模型学到胎儿超声中的通用结构表示
- 提供额外的提示式图像-结构监督
- 在视觉语言模型第一阶段训练中作为辅助数据源使用

它不直接改变最终任务标签体系。

也就是说：

- 最终任务仍然是你的 `13` 类
- 公开数据只是辅助训练资源

## 2. 当前训练时，各数据分别怎么用

### 2.1 纯视觉基线 `MobileUNet-FPN`

使用数据：

- 只用目标域 `13` 类数据

具体输入来源：

- `prepared/a4c13`

用途：

- 训练纯视觉基线
- 产出纯视觉最佳权重
- 给后续视觉语言模型提供视觉初始化权重

### 2.2 提示式视觉语言模型第一阶段

使用数据：

- 目标域 `a4c13`
- 公开数据 `public_second_trimester`

具体输入来源：

- `prepared/prompt_seg`

用途：

- 让模型在提示式任务上先看到更多结构样本
- 建立文字提示和超声区域之间的对应关系
- 作为第二阶段目标域精调前的辅助预训练

### 2.3 提示式视觉语言模型第二阶段

使用数据：

- 只保留目标域 `a4c13`

具体输入来源：

- `prepared/prompt_seg`

用途：

- 回到你的真实项目目标
- 做最终的目标域精调
- 得到当前最优 `best.pt`

### 2.4 最终 `13` 类评估

使用数据：

- 只用目标域 `13` 类测试集

具体输入来源：

- `prepared/a4c13/testing`

用途：

- 计算 `IoU`
- 计算 `Dice`
- 计算 `mAP@50`
- 计算 `mAP@50:95`

## 4. 云端训练时需要哪些数据

如果你要在云端从零复现当前结果，至少需要：

### 4.1 必须放到云端的目标域数据

需要上传：

- `FOCUS-dataset/`
- `标注/training2.xml`
- `标注/validation2.xml`
- `标注/testing2.xml`

或者你也可以直接上传已经生成好的：

- `prepared/a4c13/`

### 4.2 必须放到云端的公开辅助数据

需要上传：

- `Fetal Echocardiography Second Trimester`

建议放到：

```text
/root/autodl-tmp/project/segmentation/public-datasets/Fetal Echocardiography Second Trimester
```

### 4.3 如果只是快速复现训练，不想重复数据准备

你也可以直接上传已经整理好的：

- `prepared/a4c13/`
- `prepared/prompt_seg/`

这样可以跳过原始数据处理步骤。

## 5. 本地如何获取这些数据

### 5.1 获取目标域数据

目标域数据来自你自己已有的：

- XML 标注文件
- 对应超声图像

当前本地已存在于：

- [标注](/Users/mico/Documents/za/git/segmentation/标注)
- [FOCUS-dataset](/Users/mico/Documents/za/git/segmentation/FOCUS-dataset)

### 5.2 获取公开辅助数据

公开辅助数据需要你手动下载：

- 数据集名：`Fetal Echocardiography Second Trimester`

下载后建议放到：

```text
/Users/mico/Downloads/Fetal Echocardiography Second Trimester
```

然后运行：

```bash
python3 backend/scripts/prepare_prompt_seg_data.py \
  --a4c-root prepared/a4c13 \
  --public-root "/Users/mico/Downloads/Fetal Echocardiography Second Trimester" \
  --output-root prepared/prompt_seg \
  --force
```

## 6. 云端如何获取这些数据

### 6.1 方案一：从本地上传原始数据

这是最稳的方式。

你把本地已有的数据上传到云端：

- `FOCUS-dataset/`
- `标注/`
- `Fetal Echocardiography Second Trimester/`

上传后在云端运行数据准备脚本。

### 6.2 方案二：从本地上传已处理数据

如果你想更快，可以直接上传：

- `prepared/a4c13/`
- `prepared/prompt_seg/`

这样云端就可以直接训练。

### 6.3 方案三：只部署，不训练

如果你不是重新训练，而只是部署当前最优模型，则云端不一定需要这些原始数据。

此时只需要：

- 代码
- 最优权重 `best.pt`
- 文本编码器目录

也就是说：

- 训练需要数据
- 纯部署不一定需要训练数据
